# Take-India

Take-India is a WhatsApp-first booking, payment, and reputation operating system for Indian local businesses.

This repository contains Phase 1 only: the FastAPI foundation, merchant authentication and tenancy, the universal appointment/batch/custom-order booking engine, a public Next.js storefront, and a React/Vite merchant dashboard.

Payments, WhatsApp automation, retention, reputation workflows, and production deployment are intentionally deferred.

Detailed local setup instructions will be completed in `docs/local-development.md` as the implementation progresses.
